# 非DOM影像道路提取适配说明

## 问题分析

当前使用的影像可能不是DOM（数字正射影像），而是普通卫星影像。非DOM影像存在以下问题：

1. **透视变形**：建筑物、道路可能因为视角而产生透视变形
2. **地形起伏**：道路可能因为地形起伏而变形
3. **方向偏差**：道路的实际方向可能与OSM标注方向存在较大偏差
4. **阴影不一致**：建筑物和树木的阴影方向可能不一致

## 算法适配改进

### 1. 角度约束放宽
- **原参数**：SIGMA = 45°（仅分析OSM方向±45°的线段）
- **新参数**：SIGMA = 60°（放宽到±60°，适应非DOM影像的方向偏差）

### 2. 峰值约束降低
- **原参数**：LAMBDA = 1.5（峰值需≥1.5倍次峰值）
- **新参数**：LAMBDA = 1.2（降低到1.2，更容易满足约束）

### 3. 方向验证放宽
- **原策略**：如果估计方向与OSM差异>67.5°，使用OSM方向
- **新策略**：
  - 允许90°差异（非DOM影像）
  - 差异在60-90°之间时，使用加权平均（估计方向30% + OSM方向70%）

### 4. 边缘检测增强
- 使用多尺度边缘检测（4种方法）
- 添加梯度幅值边缘检测
- 降低Canny阈值，检测更多边缘

### 5. 线段检测放宽
- 使用更宽松的霍夫变换参数
- 降低最小线段长度要求
- 允许更大的线段间隙

### 6. 过滤条件放宽
- 灰度方差阈值：1500 → 2000
- 灰度值范围：30-220 → 20-230
- 如果过滤后无线段，使用所有检测到的线段

## 建议

1. **优先使用DOM影像**：如果可能，建议使用DOM（数字正射影像）进行道路提取，效果会更好
2. **参数调整**：如果效果仍不理想，可以进一步调整参数：
   - 增加SIGMA到75°或更大
   - 降低LAMBDA到1.1
   - 进一步放宽过滤条件

## 当前参数配置

```python
SIGMA = 60.0  # 角度约束阈值（度）
LAMBDA = 1.2  # 峰值约束
max_angle_diff = 90.0  # 允许的最大角度差异
line_variance_threshold = 2000  # 线段灰度方差阈值
gray_range = (20, 230)  # 灰度值范围
```
