## 使用建议

### 选择合适的结果

**1. 需要高精度道路边界**
- 推荐: `conservative/` (Google数据)
- 特点: 最严格，不会超出边界

**2. 平衡精度和覆盖率**
- 推荐: `standard/` 或 `moderate/` (Google数据)
- 特点: 适中扩张，适合大多数场景

**3. 确保道路完整性** ⭐ **当前推荐**
- 推荐: `aggressive/` 或 `aggressive_bing/`
- 特点: 最大扩张，确保不遗漏

**4. 对比不同数据源**
- Google: `aggressive/`
- Bing: `aggressive_bing/`
- 可对比两个数据源的差异

## 技术特性

### 已实施的8项优化
1. ✅ **LRU缓存系统** - 避免重复计算
2. ✅ **增量式mask更新** - 提高效率
3. ✅ **多指标融合边界检测** - 5指标投票机制
4. ✅ **自适应阈值** - 根据影像质量动态调整
5. ✅ **智能中心线偏移** - 平衡左右复杂度
6. ✅ **后处理平滑** - 形态学操作+高斯平滑
7. ✅ **早停策略** - 检测收敛自动停止
8. ✅ **边界检测增强** - 防止超出真实边界

### 边界检测5指标
1. SSIM（结构相似性）
2. 梯度强度
3. 纹理变化
4. 颜色一致性
5. 边界强度
