## 两种输出模式

### 1. Visualization模式（可视化分析）

**用途**: 用于结果分析、质量检查、算法调优

**输出结构**:
```
data/output/results/visualization_{DATA_SOURCE}/
├── {image_name}_mask.tif           # GeoTIFF格式mask（带地理配准）
├── {image_name}_overlay.png        # 可视化叠加图（红色mask+原图）
├── {image_name}_similarity_curve.png  # SSIM扩张曲线
└── summary.txt                     # 处理统计信息
```

**输出格式**:
- **Mask**: GeoTIFF，单通道uint8，背景0，前景1
- **Overlay**: PNG，RGB，300 DPI
- **Curve**: PNG，SSIM曲线图

**适用场景**:
- ✅ 算法效果评估
- ✅ 参数调优
- ✅ 结果可视化展示
- ✅ GIS分析

**示例**:
```python
DATA_SOURCE = 'google'
MODE = 'visualization'
```
输出到: `data/output/results/visualization_google/`

### 2. Annotation模式（训练数据生成）⭐

**用途**: 生成深度学习训练数据集

**输出结构**:
```
data/output/results/dataset_{DATA_SOURCE}/
├── images/
│   ├── {image_name}.jpg           # JPG格式图像
│   ├── ...
│   └── (11个文件)
├── masks/

│   ├── ...
│   └── (11个文件)

```

**输出格式**:
- **Images**: JPG格式，RGB三通道，质量95%
- **Masks**: PNG格式，单通道uint8

**Mask格式验证**:

**适用场景**:
- ✅ 深度学习模型训练
- ✅ 语义分割数据集制作
- ✅ 数据增强
- ✅ 模型评估

**示例**:
```python

MODE = 'annotation'
```
输出到: `data/output/results/dataset_google/`

## 技术特性

### 边界检测参数（固定aggressive配置）

| 参数 | 值 | 说明 |
|------|-----|------|
| 梯度阈值 | 2.5 | 边缘检测灵敏度 |
| 梯度强阈值 | 4.0 | 强边缘判定 |
| 纹理阈值 | 0.6 | 纹理变化检测 |
| 纹理强阈值 | 1.0 | 强纹理变化 |
| 颜色差异阈值 | 40 | 颜色一致性 |
| 颜色强阈值 | 60 | 强颜色差异 |
| 最低投票数 | 3 | 边界判定要求 |
| 最低强投票数 | 1 | 强指标要求 |

### 核心优化

1. **LRU缓存系统** - 避免重复计算
2. **多指标融合** - 5指标投票（SSIM, 梯度, 纹理, 颜色, 边界强度）
3. **自适应阈值** - 根据影像质量动态调整
4. **智能偏移** - 平衡左右复杂度
5. **后处理平滑** - 形态学操作+去噪
6. **早停策略** - 自动检测收敛

## 常见问题

### Q1: 如何切换数据源？

修改`DATA_SOURCE`参数即可:
```python
DATA_SOURCE = 'google'  # 或 'bing'
```

### Q2: 如何同时生成两种输出？

需要运行两次，每次使用不同的`MODE`:
```python
# 第一次运行
MODE = 'visualization'
# 运行 python roadmasktest.py

# 第二次运行
MODE = 'annotation'
# 再次运行 python roadmasktest.py
```

### Q3: Mask的值为什么是0和255？

这是深度学习训练数据的标准格式:
- **0**: 背景（非道路区域）
- **255**: 前景（道路区域）

在训练时通常会归一化为0和1。

### Q4: 生成的数据可以直接用于训练吗？

可以！格式完全符合标准：
- Images: JPG格式，RGB三通道
- Masks: PNG格式，单通道，背景0前景255

可直接用于PyTorch/TensorFlow等深度学习框架。

### Q5: 如何验证mask格式？

使用提供的验证代码:
```python
import cv2
import numpy as np

mask = cv2.imread('path/to/mask.png', cv2.IMREAD_UNCHANGED)
print(f'Shape: {mask.shape}')  # 应该是(1024, 1024)
print(f'Dtype: {mask.dtype}')  # 应该是uint8
print(f'Values: {np.unique(mask)}')  # 应该是[0, 255]
```
