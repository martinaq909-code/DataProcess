# 道路Mask标注指南

## 🎯 标注目标

为道路语义分割任务创建高质量的训练数据。

---

## 📐 标注定义

### 包括（标注为道路）
✅ **主要车行道**
- 高速公路、主干道、次干道
- 所有机动车可通行的路面
- 包含路面上的车道线、标识

✅ **辅助车道**
- 转弯车道
- 匝道、引道
- 应急车道（高速公路）

✅ **路口区域**
- 交叉口内部的路面
- 斑马线区域（如果是在车行道范围内）

### 不包括（不标注为道路）
❌ **人行设施**
- 人行道
- 人行天桥/地下通道

❌ **非机动车设施**
- 自行车道（如果明显分隔）
- 停车位（路边停车区）

❌ **其他地物**
- 绿化带、中央隔离带
- 建筑物、树木阴影
- 车辆本身

---

## 🖊️ 标注规则

### 1. 边界定义

**优先使用以下特征作为边界**：
1. **路缘石**（最可靠）
2. **路面颜色明显变化**（如沥青→人行道砖）
3. **绘制的道路边线**
4. **绿化带边缘**

**边界原则**：
- 精确到像素级别
- 弯道处保持平滑曲线
- 路口处连接自然

### 2. 特殊情况处理

#### 阴影区域
```
如果道路被树荫、建筑阴影覆盖：
✅ 仍然标注为道路（根据道路延续性推断）
❌ 不要因为看不清就不标注
```

#### 遮挡情况
```
如果道路被车辆遮挡：
✅ 标注车辆占据的道路区域
理由：车辆下方仍然是道路
```

#### 停车场
```
路边停车位：❌ 不标注
大型停车场：❌ 不标注
临时停车的车道：✅ 标注
```

#### 施工区域
```
如果道路在施工：
✅ 标注可见的道路部分
❌ 不标注被完全覆盖的区域
```

### 3. 质量标准

**高质量标注应该**：
- ✅ 边界平滑，无锯齿
- ✅ 路口连接自然
- ✅ 跟随实际道路边缘
- ✅ 与邻近图像一致

**常见错误**：
- ❌ 边界不精确（相差>2像素）
- ❌ 包含了人行道
- ❌ 路口处留有间隙
- ❌ 遗漏了部分道路

## 🛠️ 标注工具使用

### 推荐工具

#### 选项1: LabelMe（轻量级）
```bash
# 安装
pip install labelme

# 启动
labelme images/ --output annotations/ --labels road,background
```

**优点**：简单易用，适合快速标注  
**缺点**：功能相对简单

#### 选项2: CVAT（专业级）
推荐用于大规模标注项目

**在线版本**：https://app.cvat.ai/  
**本地部署**：
```bash
git clone https://github.com/opencv/cvat
cd cvat
docker-compose up -d
```

**优点**：功能强大，支持协作  
**缺点**：需要配置

## 📝 标注流程

### 1. 准备阶段
```bash
# 创建目录结构
mkdir -p data/annotations/{images,masks,metadata}

# 复制需要标注的图像
cp data/output/results/dataset_google/images/*.jpg data/annotations/images/
```

### 2. 标注阶段

**每张图像的标注步骤**：
1. **快速浏览**（5秒）- 识别道路类型和复杂度
2. **粗略勾画**（30秒）- 快速画出道路大致轮廓
3. **精细调整**（1-2分钟）- 修正边界细节
4. **质量检查**（20秒）- 放大检查关键区域
5. **保存并继续**

**时间预估**：
- 简单道路（直道）：2-3分钟/张
- 中等复杂度：4-5分钟/张
- 复杂路口：5-8分钟/张

### 3. 导出阶段

**LabelMe导出**：
```bash
# 转换为mask格式
python scripts/convert_labelme_to_masks.py \\
    --input data/annotations/labelme_json/ \\
    --output data/annotations/masks/
```

**CVAT导出**：
- 格式选择：`Segmentation mask 1.1`
- 导出为PNG格式

## 🔍 质量控制

### 自查清单

标注完成后，检查以下几点：

- [ ] **完整性**：所有可见道路都已标注
- [ ] **准确性**：边界沿着真实道路边缘
- [ ] **一致性**：相邻图像的标注风格一致
- [ ] **无遗漏**：路口、匝道等复杂区域都已处理
- [ ] **格式正确**：导出的mask是单通道PNG，值为0/255

### 常见问题自检

**Q: 道路边界不清晰怎么办？**
A: 参考相邻区域和道路延续性，做合理推断

**Q: 两条道路在路口重叠？**
A: 标注为一个连续区域，不要留间隙

**Q: 标注速度太慢？**
A: 使用快捷键、多边形工具加速；前10张会慢，后面会快

## 🎓 标注技巧

### 1. 提高效率
- 使用**多边形工具**而非画笔（更精确）
- 设置合适的**放大倍率**（2-3倍）
- 使用**快捷键**（保存、下一张等）
- **批量相似场景**一起标注（保持一致性）

### 2. 提高质量
- **对比参考**：打开OSM数据或Google Street View作参考
- **边标注边检查**：完成一张立即review
- **休息放松**：每标注10张休息5分钟

### 3. 困难情况处理原则
```
遇到不确定的情况：
1. 先查看OSM数据（参考）
2. 查看邻近图像（一致性）
3. 按保守原则（宁缺勿滥）
4. 在metadata中记录疑问
```

## ✅ 验收标准

标注完成后，使用评估脚本检查：

```bash
# 抽查10张，人工review
python scripts/evaluate_masks.py \\
    --pred_dir data/annotations/masks/ \\
    --gt_dir data/annotations/masks_verified/ \\
    --output_dir data/annotations/qa/ \\
    --report qa_report.json
```

**验收要求**：
- 所有图像都已标注
- 边界精度：目视检查误差<3像素
- 格式正确：单通道PNG，0/255值
- 一致性：相同场景标注风格一致
