## 技术实现
道路mask生成功能采用了非对称交替扩张算法：
1. 从道路中心线开始，进行初始缓冲
2. 通过Laplacian方差衡量区域复杂度
3. 使用SSIM（结构相似性）判断扩张停止条件
4. 允许中心线偏移以更好地适应道路形状
5. 合并所有道路的mask为一张图像

## 结论
道路mask生成功能成功运行，处理了所有11个测试图像，生成了对应的mask文件、可视化叠加和相似性曲线。算法能够根据道路的复杂度和图像特征自适应调整mask的宽度，生成了合理的道路区域mask。

生成的mask文件可用于后续的道路提取、道路宽度分析或其他地理空间分析任务。
